analysiert lokale Deklarationen nur im Rumpf; die Methodensignatur wird von `_methods` nicht weitergegeben.
Ein Aufruf über einen Parameter eines schreibenden Kerntyps wird daher nicht transitiv als schreibend erkannt.
Ausführbare isolierte Probe im Repo (`python3 -`):

```python
from pathlib import Path
p = Path('tools/check-architecture.py').resolve()
n = {'__file__': str(p)}
exec(compile(p.read_text().split('# Self-test: every rule')[0], str(p), 'exec'), n)
w = n['core_writers'](['public class A { public void Write(Dgroup d) { d.Set(0, (byte)1); } }',
                       'public static class B { public static void Go(A a, Dgroup d) { a.Write(d); } }'])
print(w, n['scene_violations']('B.Go(a, state);', w))
```

Ergebnis `{'A.Write': False} []`: `B.Go` und der Szenenaufruf bleiben unerkannt. Dies zeigt eine Lücke des
Architekturchecks, keinen nachgewiesenen Zustandszugriff einer bestehenden Szene.

## Befunde

**P2 – Bildnachholung trennt Kern- und Menüausgabe.** [`ProgramHost.Frame`](https://github.com/kaaasi/traders-redone/blob/9efc2d2001c3f9625e299cbf6027a7cf28abf0a4/src/Traders.App/ProgramHost.cs#L97) lässt `Machine.Advance` alle fehlenden Bilder verarbeiten, ruft `Scene.NextFrame` aber nur einmal auf und spielt danach alle Ereignisse ab. [`HostGame.Update`](https://github.com/kaaasi/traders-redone/blob/9efc2d2001c3f9625e299cbf6027a7cf28abf0a4/src/Traders.App/HostGame.cs#L82) übergibt bei mehreren fälligen Bildern nur den letzten Takt. Ein Update mit 15 fälligen Bildern liegt unter der Grenze von 0,25 s. Dadurch laufen Palette/Seitenwechsel zeitlich hinterher bzw. werden durch `Apply` vorzeitig beendet; das sichtbare Menübild weicht ab. Die folgenden Aktionen mit identischer Uhr und ohne Tasten ergeben bei Bild 35 unterschiedliche Pixel. **Testlücke:** `ProgramHostTests` geht ausschließlich bildweise vor; die bildweisen Menü-Differenztests testen diesen Host-Nachholpfad nicht.

Ausführbarer Beleg: folgende Datei temporär als `tests/Traders.Tests/App/ReviewFrameProbe.cs` anlegen, Originaldaten wie unten einbinden und `dotnet test tests/Traders.Tests/Traders.Tests.csproj -c Release --filter FullyQualifiedName~ReviewFrameProbe` ausführen:

```csharp
using Traders.App;
using Traders.App.Rendering;
using Traders.Core;
namespace Traders.Tests.App;
public class ReviewFrameProbe
{
    [GameDataFact]
    public void Jump_matches_individual_frames()
    {
        var a = new ProgramHost(TestGameData.DosDir, new RecordedClock([12345678]));
        var b = new ProgramHost(TestGameData.DosDir, new RecordedClock([12345678]));
        for (long f = 0; f <= 35; f++) a.Frame(f, []);
        for (long f = 0; f <= 20; f++) b.Frame(f, []);
        b.Frame(35, []);
        var x = new uint[320 * 200]; var y = new uint[320 * 200];
        FramePresenter.Present(a.Driver.Vram, a.Driver.DisplayStart, a.Layers.Dac.Registers, x);
        FramePresenter.Present(b.Driver.Vram, b.Driver.DisplayStart, b.Layers.Dac.Registers, y);
        Assert.Equal(x, y);
    }
}
```

Ergebnis: **rot**, erstes abweichendes Pixel Index 98: `4278206817` gegen `4278206850`. Probe in separater Kopie, kein Produktionscode verändert. Sie vergleicht denselben Host unter zwei Takten; sie behauptet keinen separaten RefEmu-Pixelvergleich für diesen Zwischenstand.

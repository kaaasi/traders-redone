**P3-1 Architekturregel prüft die Rückrichtung nur für Core/Assets/Vga/Audio.** Kommentar
[`tools/check-architecture.py:11`](https://github.com/kaaasi/traders-redone/blob/2edddc167d41eefe30006f1358b87e20c744f8ae/tools/check-architecture.py#L11) sagt „nothing depends back on it“; geprüft werden aber

`src/Traders.RefEmu/Traders.RefEmu.csproj` → `python3 -I tools/check-architecture.py` meldet „Architekturgrenzen geprüft“, rc 0
(gleiches gilt für Viewer/Tools). Abnahmekriterium der Spur („Kern nicht von App“) ist erfüllt (Core → App: rc 1). Vorschlag:
Kommentar präzisieren oder alle `src/*` außer Tests gegen Referenzen auf `Traders.App` prüfen.

**P3-2 Ring der Effektaufträge: 16 offene Aufträge sehen leer aus.** [`docs/analyse/TON.md:72`](https://github.com/kaaasi/traders-redone/blob/2edddc167d41eefe30006f1358b87e20c744f8ae/docs/analyse/TON.md#L72)
beschreibt den Überlauf nur als „der 17. überschreibt den ersten“. Nach dem 16. offenen Auftrag ist aber Kopf = Ende (= 0), und
`0000:077B` (`cmp bx,[0x417]`, `jnz`/sonst Sprung nach `07DE`) wertet das als leer – alle 16 bleiben ungespielt, bis ein
weiterer kommt. Beleg: RefEmu-Probe in temporärer Kopie (wie `Effect_request_with_adlib…`, `Effects(1)`, 16 × `21A7:0054`):
`Read16(rt, 0x0417) == Read16(rt, 0x0419) == 0` → bestanden. Für R10 im Text ergänzen.

**P3-3 Ungenauigkeit `27C6:00AC`.** [`27C6_0043_eingabe_zeitgeber.md:31`](https://github.com/kaaasi/traders-redone/blob/2edddc167d41eefe30006f1358b87e20c744f8ae/docs/routines/27C6_0043_eingabe_zeitgeber.md#L31):
„Kopf = Ende“ – der Code kopiert nur das niedrige Byte (`mov al,[es:041A]` / `mov [es:041C],al`, `27C6:00C5`). Ohne Folge für
den Port (BIOS-Puffer hat keine Entsprechung), nur Wortlaut.

Keine P0–P2.

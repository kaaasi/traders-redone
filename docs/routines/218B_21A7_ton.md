# 218B:0002 / 218B:0094 / 218B:013A / 218B:0153 / 218B:01A4, 21A7:000D / 21A7:0043 / 21A7:0054 / 21AF:0002, 27C6:041B / 27C6:0416, 0000:4F65 / 0000:5079 – Tonsteuerung

- **Ladebild-Adresse:** Segment `218B` (Dateioffset `0x24EB0`, `0002` bei `0x24EB2`), `21A7` (`0x25070`), `27C6:041B`.
- **Aufgabe:** Musik über den residenten Treiber `FXDRIVER` (`int 64h`) starten, spielen, abfragen, stoppen; Effekte an die
  Effektmaschine (`0000:06FE`–`15B1`, Befund `0000_0750_effekte.md`) bzw. den PC-Lautsprecher (`2850`) geben; Zeitgeber-Rückruf
  `CS:0416/0418` in Segment `27C6` setzen. Überblick und Treiberfunktionen: `docs/analyse/TON.md` §2–4.
- **Aufgerufen von / Phase:** `1777` (Start `0002`, `000D`, `0043`, Menü `0094(1, 2)`), Vorspann `0DFD:02FE` (`0094(0, 0)`),
  Ende `20B3:0060` (`0094(2, 3)`), 144 Aufrufstellen von `21A7:0054` (alle Szenen).
- **Parameter / Rückgabe:** `0002()` → 1 Erfolg, 0 sonst; `0094(i, Merker)`; `013A()` → AL Wiedergabezustand; `0153()`;
  `01A4(x)`; `000D()` → 1; `0043()`; `0054(a, b)` (`a` wird nicht gelesen); `041B(far p)`.

## Ablauf (eigene Worte)

- `0002`: nur bei `0910` = 1 (Wortvergleich) und gesetztem `int 64h`-Vektor (`0000:3B91` = `getvect`). Fn 06h (BX = 0), Fn 05h
  (BX = 0), `186C:02C6(12060h)`; Nullzeiger (Vergleich `0000:4F65` normalisiert: Segment + Offset/16 und Offset & 0Fh, d. h.
  auch `FFFF:0010`) → 0. Sonst 24 × Fn 10h (BX = Nummer, CX = Segment, DX = Offset), nach jedem Puffer Zeiger += 0C04h als
  Huge-Zeiger (`0000:5079`, Laufzeit: Übertrag des Offsets addiert 1000h zum Segment, dann normalisiert – der erste Puffer bekommt den
  Zeiger der Zuteilung unverändert). `10A3` = 1, Rückgabe 1. Das Ergebnis von Fn 06h wird nicht geprüft.
- `0094(i, m)`: nur bei `10A7` ≠ 0 und `10A3` ≠ 0. `0153`; ist `10A9` ≠ i: `186C:0A6C(Name, DS:10A0+i)` (Datei suchen,
  entfällt), Fn 00h mit BX:CX = Zeiger `DS:1094+4i` (Segment:Offset), `10A9` = i. Fn 18h mit BX = Bit 1 von m, `01A4(3)` bei
  Bit 0 sonst `01A4(7Fh)`, Fn 1Ah, Fn 01h, `10A5` = 1. Der Index wird 16-bittig gerechnet (`shl bx,1` zweimal).
- `013A`: `10A3` = 0 → AL = 0 ohne Treiberaufruf; sonst AL = BL von Fn 12h. `0153`: ist `013A` ≠ 0, Fn 03h und `10A5` = 0 –
  steht der Treiber, bleibt `10A5` unverändert. `01A4(x)`: Fn 1Bh mit BX = x.
- `000D`: `0910` = 1 → `0000:06FE` (Effektmaschine zurücksetzen), dann `041B(0000:0732)`; sonst `041B(2850:0061)`. AX = 1.
- `0043`: `0910` = 1 → `0000:0724`.
- `0054(a, b)`: `10A5` ≠ 0 → `0153` und `000D`. Dann nur bei `10A7` ≠ 0: `0910` = 1 → `0000:0750(b)`, sonst `2850:00CC(b)`
  (bei `21A7:0082`, in der Segmentkarte `21AF:0002`).
- `041B(p)`: `cli`, `CS:0416` = Offset, `CS:0418` = Segment, `sti`. Anfangswert `27C6:041A` (ein `retf`).

## C#-Umsetzung
`src/Traders.Core/Sound/SoundControl.cs`, `SoundCommand.cs`: arbeitet auf `Dgroup` und gibt statt der Aufrufe `SoundCommand`s aus
(Treiberaufruf mit den absichtlich gesetzten Registern, Effektmaschine zurücksetzen/anhalten/Effekt, PC-Lautsprecher, Rückruf);
den Wiedergabezustand (Fn 12h) liefert `IMusicDriverState` als explizite Eingabe, Vektor und Zuteilung bekommt `Start` vom Host.
Der Rückruf `27C6:0416/0418` liegt als Ladebildadresse in `SoundControl`. `[APPROX]`: die Dateisuche `186C:0A6C` entfällt
(F2 = A); der PC-Lautsprecher wird nicht gespielt (Nutzer 11.11.2026), der Befehl bleibt für den Vergleich.

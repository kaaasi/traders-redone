- **Ladebild-Adresse:** Segment `0000` (Dateioffset `0x3600`), Code `06FE`–`151D`, Sprungtabelle `151E`, Startzeiger `15B2`,
  Starttabelle `15B6` (87 Einträge, Effekte 00h…56h), Klangfolgen ab `1664`, Instrumente über `1B0D` (200 Zeiger), Variablen
  `03EC`–`06FD` (Stimmenblöcke `042B` + 43h·v, v = 0…9, Zeiger `06C9`, Kanalversatz `06DD`).
- **Aufgabe:** OPL2-Soundeffekte, unabhängig von `FXDRIVER`: Aufträge in einen Ring, je Zeitgebertick (72,82 Hz) Aufträge starten
  und alle Stimmen einen Schritt in ihrem Bytecode weiterführen. `DS` = `CS` (alles im eigenen Codesegment).
- **Aufgerufen von / Phase:** `21A7:000D` (`06FE`, dann Rückruf `27C6:041B(0000:0732)`), `21A7:0043` (`0724`), `21A7:0054`
  (`0750(b)`); `0732` aus der Zeitgeberkette über `27C6:0416`. `07E2` und `123B` (Abfragen) ruft das Spiel nicht.
- **Parameter / Rückgabe:** `0750(Wort)`; die übrigen ohne. Keine Rückgabe, die der Aufrufer liest.

## Ablauf (eigene Worte)

- `06FE`: `[0415]` = `[15B2]`, `0812`, Ring leer (`0417` = `0419` = 0). `0724`: nur `0812`.
- `0812`: `03F0` = 0, Zufall `03F8` = 1234h, OPL 01h = 20h, 08h = 0, BDh = 0, `03F3` = 0; für v = 9…0: außer v = 9 die
  Pegel 40h/43h+Kanal = 3Fh; `131F` (Block v ab Byte 3 auf 0, `[25]` = FFh, `[8]` = 0, `[29]`/`[2B]` = 1407h (`ret`), `[35]` = 1).
- `0750(w)`: Wort nach `041B + [0417]` (**Byteversatz**, nicht Wortversatz), `[0417]` = (`[0417]`+1) & 0Fh. Kein Überlaufschutz
  (#76 R3H-2): mit dem 16. offenen Auftrag ist Kopf = Ende, der Ring wirkt leer, alle 16 gehen verloren; jedes Wort überschreibt das hohe
  Byte des vorigen, Platz 15 schreibt sein hohes Byte in Byte 0 (Lautstärke) von Stimme 0 (`042B`).
- `0732`: `0770`, `0866`, `121C`.
- `0770`: solange `[0419]` ≠ `[0417]`: niedriges Byte b von `041B + [0419]`, Folge `[[0415] + 2b]`, deren erstes Wort Stimme
  (BL) und Vorrang (BH). Stimme 0 → `03F3` = 0. Start nur bei Vorrang ≥ `[Block+8]` (vorzeichenbehaftet): `131F`, `[8]` =
  Vorrang, Zeiger hinter das Kopfwort, `[25]` = `[26]` = FFh, `[5]` = 1, `03F0` = 1, außer Stimme 9 `13BE` (Kanal stumm:
  60h/63h/80h/83h = FFh, B0h+v = 0 und dann 20h; entfällt bei Rhythmus `03F1` ≠ 0 für v ≥ 6). Dann `[0419]` weiter (mod 16).
- `0866` (nur bei `03F0` ≠ 0): v = 9…0 (`03EF`), aktive Stimmen (`[5]` ≠ 0): `03FC` = Kanalversatz; bei `[40]` ≠ 0 `[25]` =
  `03F2`; `[26]` += `[25]`, nur bei Übertrag ein Zeitschritt: `[5]` − 1; bei 0 Ereignisse lesen, sonst Tasten-aus bei `[21]` bzw.
  `[35]` (nicht Stimme 9). Danach je Tick `call [29]` und `call [2B]` (1407h nichts, 1408h Vibrato, 148Ah Gleiten, 1461h Tabelle).
- Ereignis (`08D3`, `lodsw`): AL < 80h Note (Oktave im hohen, Halbton im niedrigen Halbbyte, AH Dauer): `10B5` (Frequenz aus
  `06E6`, Transponierung `[12]`, Oktave `[7]`, Feinstimmung `[24]`, Beugung `[42]` über die Tabellen `[020C + 2·Halbton(+2)]`),
  `116A` Taste an, `11C2` Dauer (`03EC`, `[5]`; Zufallslänge `[36]` über `150E`, Tasten-aus-Anteil `[2D]`), bei `[32]`/`[33]`
  ein Anschlagbyte und neue Pegel; Dauer 0 → sofort nächstes Ereignis. AL ≥ 80h: Befehl `AL & 7Fh` (> 70h Ende) über `151E`,
  AH Parameter. 4Ah…70h zeigen hinter die Tabelle in Daten.
- Befehle (Auswahl): 00/01 Schleife, 02 Effekt starten (wie `0770`, ohne `03F3`), 04 Sprung, 05/06 Unterfolge mit Stapel
  `[0A+2·[9]]`, 08 Ende, 09/20/21 Pause (mit/ohne Tasten-aus, neu anschlagen), 0A OPL-Register, 0B Legato, 0D Tabellenschritt,
  0E/33 Stimme anhalten/stummschalten, 10 Instrument (`1352`), 11/12 Gleiten, 15 Vibrato, 1C/1D gemeinsamer Zähler und Warten,
  1E/30/2C/2D Lautstärke (`127A`), 2E/2F BDh-Bits, 35 Zufallsfrequenz, 39 Beugung (`0CBD`, ohne Nulltest), 3D Tempo ± mit
  Sättigung, 41–46 Rhythmus (Instrumente 6–8, Schläge auf BDh, Pegel).
- `0E8A` (Rhythmusschlag) schreibt BDh zweimal, das zweite Mal nur über den Datenport ohne neue Registerwahl.
- `148A` (Gleiten): ergibt Halbieren (über 2DDh) bzw. Verdoppeln (unter 185h) einen 10-Bit-Wert 0, holt `pop bx` die
  Rücksprungadresse von `call [29]` (0939h) vom Stapel; das abschließende `ret` kehrt aus `0866` zurück – die restlichen Stimmen
  dieses Ticks entfallen, BX = 0939h geht in die Frequenz ein.
- `121C`: `040E` += `03F2`, bei Übertrag `040D` − 1, bei 0 `040D` = `040C` und `040F` + 1 (für Befehl 1D).
- `150E`: `03F8` = ror3(`03F8` + 9248h), Ergebnis in AX. Eigener Zustand, nicht `DS:10D2`; nur `0812` setzt ihn zurück.
- OPL-Schreiben `11FA`: AH Register, AL Wert, Wartezeiten über `in 388h` (4 bzw. 23 Lesungen), DX danach 389h.

## Seiteneffekte in Reihenfolge
Nur OPL2-Registerschreibungen (Ports 388h/389h) in Programmreihenfolge; kein `DS:10D2`, keine Uhr, keine Grafik.

## C#-Umsetzung
`src/Traders.Audio/Effects/EffectMachine*.cs` auf einer Kopie des 64-KiB-Fensters ab Segment `0000` aus `T.EXE`
(`EffectImage.FromExe`, alle Tabellen zur Laufzeit, R9PL-3), Befehl für Befehl auf den 8086-Registern übertragen (Restwerte von
Registern zwischen Unterroutinen, Überlappungen und der Stapelrutsch in `148A` wirken wie im Original). Ausgabe
`EffectWrite(Tick, Register, Wert)`, Tick = Aufrufnummer von `0732` (R9PL-2).

- `[APPROX]` Befehle 4Ah…70h und Routinenadressen außer 1407h/1408h/1461h/148Ah: das Original führte Daten aus; der Port wirft
  `NotSupportedException`. Kein Effekt des Spiels nutzt sie.
- `[APPROX]` Das Fenster ist unreloziert: Lesezugriffe auf relozierte Wörter (außerhalb `0208`–`2683`, z. B. Beugung bei Halbton
  12…15 über `CS:0100`…, Aufträge > 56h mit Zeigern hinter Segment `0000`) hängen im Original vom Ladesegment ab. Die Effekte
  00h…56h lesen keine.

## Prüfung
`tests/Traders.Tests/Audio/EffectsDifferentialTests.cs`, `EffectsSequenceTests.cs`, `EffectsGameDifferentialTests.cs`
(Harness `EffectsHarness.cs`, RefEmu `LoadOnly` mit Direktaufrufen bzw. laufendes Spiel mit `FXDRIVER`): je Aufruf OPL-Folge
(Register, Wert, Reihenfolge) und `CS:03EC`–`06FD`, am Fallende das ganze Fenster.

- Jeder Effekt 00h…56h einzeln bis zum Ende (Endlosschleifen 4000 Ticks).
- Schnelle Auftragsfolgen bis 20 je Tick (Ringüberlauf), Aufträge mit hohem Byte, `0724` dazwischen.
- Zufällige, wohlgeformte Folgen in einem freien Bereich (`CS:3000`, Starttabelle `CS:3800`) für alle Befehle 00h…49h, mehrere
  Stimmen gleichzeitig (150 Fälle × 400 Ticks; erreicht u. a. den Stapelrutsch `14C2`/`14DE`).
- Laufendes Spiel (Start mit `FXDRIVER`, Hauptmenü, neue Partie): alle Aufrufe des Spiels nachgespielt, dazu Aufträge in den Ring.
  „Effekt während Musik“ gibt es im Original so nicht: `21A7:0054` stoppt laufende Musik vor dem Effekt (Teil 1); im Hauptmenü
  ruft das Spiel `000D` nicht, die Effektmaschine tickt erst ab Spielstart.
- Gegenproben lokal rot: Ring mit Überlaufschutz, Zufall `03F8` je Effekt zurückgesetzt, Stapelrutsch weggelassen.

# 1777:000C – Hauptprogramm (`main`)

- **Ladebild-Adresse:** `1777:000C` (Dateioffset `0x1AD7C`, Kopf `0x3600`), Länge `0x1EC` bis `retf` bei `1777:01F7`
- **Aufgabe:** Kommandozeile auswerten, Programm initialisieren, Hauptmenü und Partien in einer Schleife, am Ende Ton und
  Systemschicht abbauen und eine Abschlussmeldung ausgeben.
- **Aufgerufen von / Phase:** einziger Aufrufer ist der Turbo-C-Start `0000:00E3` (`BESTAND.md` B2). Rahmen der gesamten
  Phasenfolge; die Wochen laufen in [1777_01F8_wochenschleife.md](1777_01F8_wochenschleife.md).
- **Parameter / Rückgabe:** C-Aufruf `main(argc, argv)`: `[bp+6]` = argc, `[bp+8]` = argv (Far-Zeiger auf Far-Zeiger).
  Rückgabe ohne festgelegten Wert (`AX` = Rückgabe des Ausgabeaufrufs).

## Ablauf (S: lineares Lesen)

| Stelle | Schritt |
|---|---|
| `0014`–`0116` | Für jedes Argument ab argv[1]: sechs Vergleiche mit festen Zeichenketten (`DS:091D`, `0921`, `0925`, `092B`, `0935`, `093C`) über die Laufzeitroutine `0000:42A4` (0 = gleich). Treffer setzen `DS:090E` = 1, 0, 2, 63h (Grafikkarte), `DS:0910` = 0 (Tonart) bzw. `DS:0912` = 1. Spätere Argumente überschreiben frühere. |
| `0119` | `1777:04E4` Initialisierung; Ergebnis in `DI`. `DI` ≠ 0 → sofort zum Abbau (`018C`). |
| `0126` | `0DFD:000D` Programmstart (Schrift, Ladebild, Bilder, Texte, Code-Abfrage), einmal je Programmlauf |
| `012B` | `218B:013A`; Ergebnis 0 → `21A7:000D` (Tonquelle wählen) |
| `013B` | **Schleifenanfang.** `218B:013A`; Ergebnis 0 → `21A7:0054(0, 1)` und `218B:0094(1, 2)` (Toneffekt, Musikstück) |
| `0163` | `192D:0007` Hauptmenü; `AL` = 0 → Abbau (`018C`) |
| `016E` | `DS:3CCC` = 1 → `0E31:0003` neue Partie; sonst ohne Neuaufbau weiter (z. B. geladener Spielstand) |

## Zustand
| DS-Offset | Breite | Vorzeichen | Bedeutung | gelesen/geschrieben |
|---|---|---|---|---|
| `090E` | Wort | s | Grafikkarte (1 VGA, 0 EGA, 2 Tandy, 63h Tandy-Emulation; Vorgabe −1 = erkennen, `BESTAND.md` §1.4) | geschrieben |
| `0910` | Wort | – | Tonart (0 = PC-Lautsprecher) | geschrieben |
| `0912` | Wort | – | Kommandozeilenschalter, Bedeutung offen (`BESTAND.md` §3) | geschrieben |
| `3CCC` | Byte | – | Menüergebnis „neue Partie“ (gesetzt in `192D:12A6`) | gelesen |
| `08FA` | Byte | – | siehe Ablauf | geschrieben (1) |

## Seiteneffekte in Reihenfolge
Eigener Zufall, Uhr und Grafik: keine. Ton über `218B`/`21A7` vor jedem Hauptmenü und beim Abbau; Bildschirmmodus und Interrupts
über `0D73` beim Abbau; Textausgabe der Abschlussmeldung über die Laufzeit.

**Folgen der Wochenschleife:** Rückgabe 0 (Abbruch mit Scancode 0Eh) führt zurück ins Hauptmenü; Rückgabe 1 (Partieende aus
`20B3:0005`) beendet das Programm über den Abbau – es gibt danach kein Hauptmenü mehr. Eine neue Partie ohne Programmneustart
gibt es nur über den Abbruchweg.

## C#-Umsetzung
Kein Port in Runde 2. Kommandozeile, Initialisierung und Abbau ersetzt der Host; Menüschleife und Partieende gehören zur
Phasenmaschine (R3).

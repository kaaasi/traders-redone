# 0B67:0002 / 0B67:016B / 0B67:0196 / 0B67:01B5 / 0B67:01D4 / 0B67:0206 / 0B67:0238 / 0B67:028F / 0B67:0299 / 0D73:00D3 – Seitenverwaltung und Rücklaufwarten (VGA)

- **Ladebild-Adresse:** `0B67:0002` (Dateioffset `0xEC72`), `016B`, `0196`, `01B5`, `01D4`, `0206`, `0238`, `028F`, `0299`.
- **Aufgabe:** zwei Bildseiten anlegen, anzeigen, umschalten, Zeichenseite wählen, Seite kopieren, auf den Strahlrücklauf warten
  (`0D73:00D3`: solange Bit 3 von Port 3DAh gesetzt ist, dann bis es wieder gesetzt ist).
- **Aufgerufen von:** `0002` beim Start nach der Kartenwahl; `0238`/`028F` aus `21FD:051F`/`0590`; übrige aus Szenen.
- **Parameter / Rückgabe:** `0002()` → 0 gut, 1 kein Speicher; `0238(Zeichnen: long, Zeigen: long)`; `0299(Richtung)`; übrige ohne.

## Ablauf (eigene Worte)
- `0002`: Modus 63h zuerst Tandy-Puffer (`2BA8`, nicht portiert). `23CD:04F6(Modus)`, dann Sprung über die Tabelle `CS:015B`
  (Modi 0, 1, 2, 63h). VGA (`007F`): Seite 0 = `A000:0000`, Seite 1 = `A400:0000`, Puffer `farmalloc(500h)` (`186C:02C6`) nach
  `2BAC`; null → Rückgabe 1 (Seitenzeiger sind dann schon gesetzt). Sonst `01D4`, Farbe 0, Rechteck 0,0,320,200; `0206`, Rechteck;
  Rückgabe 0. Unbekannter Modus: Sprung mit uninitialisierter Größe (nicht portiert).
- `0196`/`01B5`: `0238` = 0/1, Anzeigestart `23CD:0575` auf Seite 0/1, dann `0D73:00D3` (Rücklauf abwarten).
- `01D4`: `023A` = 0, Zeichenseite (`23CD:0570`) = angezeigte Seite; `0206`: `023A` = 1, Zeichenseite = verdeckte Seite.
- `016B`: andere Seite zeigen, danach `0206`, falls `023A` ≠ 0, sonst `01D4`.
- `0238`: Zeigen = 1 → `0196`, = 2 → `01B5`. Zeichnen ∈ {1, 2}: gleich Zeigen (beide Wörter) → `01D4`, sonst `0206`.
- `028F`: nur `0D73:00D3`. `0299`: Tabelle `CS:0372`; VGA (`0313`): Latch-Kopie `23CD:06B9` (Vektor 18) mit 3E80h Byte × 1 Zeile,
  Richtung 1: Seite 0 → 1, sonst 1 → 0. Modus außerhalb der Tabelle: nichts.

## Seiteneffekte in Reihenfolge
VGA (CRTC-Start, Zeichenseite im Treiber, VRAM), Rücklaufwarten über `0D73:00D3`. Kein Zufall, keine Uhr.

## C#-Umsetzung
`src/Traders.Vga/Layers/Pages.cs` (`GraphicsLayers.InitializePages`, `FlipShownPage`, `ShowPage0/1`, `DrawOnShownPage`,
`DrawOnHiddenPage`, `SelectPages`, `WaitForRetrace`, `CopyPage`). Warten = ein Aufruf von `IRetraceWait.WaitForRetrace`. Den
Puffer von `0002` legt der Aufrufer an (C-Laufzeit-Heap) und übergibt den Zeiger. Nur VGA; andere Modi werfen `NotSupportedException`.

## Prüfung
`tests/Traders.Tests/Vga/PageLayerTests.cs`: 120 zufällige Aufrufe von `0196/01B5/01D4/0206/016B/028F` bei zufälligen
`0238`/`023A` (auch ≠ 0/1); `0238` mit Zeichnen/Zeigen aus {0, 1, 2, 3, 10001h, 20000h, FFFFFFFFh}; `0299` mit Richtung
1/0/2/FFFFh und Modus 5; `0002` mit Puffer 8000:0000, 1234:0010 und null (Allokator im RefEmu durch `mov ax/mov dx/retf` ersetzt,
`LoadOnly` hat keinen Heap). Verglichen: ganzes DS, DAC, Zahl der Rücklaufwarten, CRTC-Start, Zeichenseite, VRAM.

# Experimente

Pro Paket ein Unterordner apN; Shell-Einstieg erhält den absoluten Ausgabeordner als erstes
Argument. Keine Zugangsdaten, keine Änderungen an Originalen. Ergebnisse nur im Ausgabeordner.
Manueller Diagnoseworkflow: experiment = experiments/apN/name.sh. Experimente sind normale,
reviewbare Dateien und dürfen integriert werden. ci/experiment.sh wird nicht mehr übernommen.

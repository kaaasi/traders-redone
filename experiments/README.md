# Experimente

Pro Spur ein Unterordner (`experiments/<spur>/`, ältere `apN/`); Shell-Einstieg erhält den absoluten Ausgabeordner als erstes
Argument und läuft lokal (`bash experiments/<spur>/<name>.sh /tmp/aus`). Keine Zugangsdaten, keine Änderungen an Originalen,
Ergebnisse nur im Ausgabeordner. Experimente sind normale, reviewbare Dateien und dürfen integriert werden; dauerhafte Befunde
gehören nach `docs/routines/` bzw. `docs/analyse/`.
